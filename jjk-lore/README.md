# JJK 知识库使用说明

> **用途**: 为 AI Agent 提供咒术回战（Jujutsu Kaisen）原著设定参考，用于验证 SEED_DATA 的 lore 准确性。
> **入口**: 先看 `索引.md` 找到正确的文件，再看具体内容。

## AI Agent 使用流程

1. **读 `索引.md`** — 根据你需要的主题（角色/术式/术语/评级/时间线）找到目标文件。
2. **读 `映射表.md`** — 理解 SEED_DATA 中的字段（p1_id, p2_tech_h 等）与 JJK Canon 的对应关系。
3. **读目标文件** — 获取详细设定内容。
4. **需要更多信息时** — 配合 `术语/术语表.md` 查基础概念，`官方设定/评级系统.md` 查等级映射。

### 典型任务示例

| 任务 | 读取顺序 |
|------|---------|
| 修改 SEED_DATA 术式选项 | 映射表.md → 术式/生得术式.md |
| 添加新角色数据 | 索引.md → 对应角色/文件 |
| 验证 era 事件准确性 | 映射表.md → 时间线/时间线.md |
| 确认评级/维度映射 | 映射表.md → 官方设定/评级系统.md |

## 扩展指南

如需添加新角色或术式：

1. 确定分类（咒术师/诅咒师/咒灵/死灭/其他 或 生得术式/通用技巧）。
2. 在对应 `.md` 文件中按现有格式添加条目。
3. 如有新的 SEED_DATA 字段映射，更新 `映射表.md`。
4. 运行 `.\check-braces.ps1`（不影响，但好习惯）。
